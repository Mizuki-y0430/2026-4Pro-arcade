# ルール・操作方法の共通フォーマット

6作品すべてに、`rules.html`・`rules.css`・`rules.js` の同じテンプレートを使用します。通常は `showcase/assets/ゲームID-rules-poster.png` の説明画像を1枚表示します。採用画像と出典は [説明画像一覧](../showcase/assets/rules-posters.md) を参照してください。

## 説明画像の表示

- 赤いタイトル帯、白い背景、黒い文字、番号付きの3区分で、操作・目標・終了条件を1枚にまとめます。ゲームごとに必要な持ち駒や得点なども記載します。
- PCでは画像を切り取らず、縦横比を保って画面内に表示します。操作リンクも画像の下に表示します。
- 画像を押すと元画像を別タブで開きます。小さい画面では拡大して読めます。
- `alt` に画像の用途を記載し、文章で読む場合は「詳しいルール・その他の操作を見る」から `games.json` の説明を確認できます。
- 説明画像の読み込みに失敗したときは、以下の図と文章の説明を表示します。追加ゲームも従来どおり文章で説明できます。
- 画像内の数値は標準設定を示します。ゲームのルール変更時には画像・文章・代替の図を一緒に更新します。

## 画像を読み込めない場合の説明

作品別の代替説明は `rules.js` の `illustratedGuides`、詳しいルールは `games.json` の `rules` / `operations` に定義します。

## ページの順番

1. ゲーム名と、何をするゲームかを一文で表示。
2. **01 めざすこと**：目標・得点の図、短い見出し、得点や目標の説明。
3. **02 操作の3ステップ**：開始 → 選択や準備 → 実行や繰り返し。各ステップの見出し・図・説明・入力表示を同じ順番で配置。
4. **03 終わりの条件**：成功・結果と、失敗・注意点の2項目。
5. 折りたたみの「詳しいルール・その他の操作」と、プレイ開始・一覧へのリンク。

## 作品ごとのデータ

```javascript
{
  summary: "何をするゲームかの一文",
  goal: {title: "目標や得点", copy: "短い説明", art: "図のキー"},
  steps: [
    {title: "開始する", copy: "説明", art: "図のキー", inputs: ["クリック・タップ"]},
    {title: "選ぶ・準備する", copy: "説明", art: "図のキー", inputs: ["Enter"]},
    {title: "実行・繰り返す", copy: "説明", art: "図のキー", inputs: ["クリック・タップ"]}
  ],
  finish: [
    {title: "成功・結果", copy: "説明", mark: "✓"},
    {title: "失敗・注意点", copy: "説明", mark: "!"}
  ]
}
```

操作は必ず3ステップ、終了・注意点は2項目にまとめます。`inputs` は実際に使える入力を記載します。自動の処理は「自動」と表示し、操作を求めません。

## 図と文章のルール

- 赤・白・黒、成功エリアの黄色、茶色のモグラなど実際のゲームで意味のある色を使用します。
- 図は操作説明用の模式図です。問題・配置・駒の例を、実際の固定画面や必ず成功する盤面だと誤解させないようにします。
- 図には `role="img"` と意味を説明する `aria-label` を付けます。同じ内容を横の文章でも説明し、色だけに意味を持たせません。
- 文字はSVGの中に詰め込まず、図の外の見出し・説明・キー表示を優先します。
- PCは操作を横3列、小さい画面は縦3段で表示します。キー・クリック・タップは同じスタイルで表示します。
- ゲーム設定を変更した際は、図、短い説明、`games.json` の詳しい説明の数値も一致させます。モグラの制限時間・ライフなどは「標準」と明記します。

図を用意していない追加ゲームは、既存の `rules` / `operations` を展開表示するため、ルールページを引き続き利用できます。サーバーから取得した文章は `textContent` で表示し、SVGには固定の図形だけを使います。
