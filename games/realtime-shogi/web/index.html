    操作とルール

    自分の駒、または持ち駒 → 緑の移動先。ターン待ちはありません。
    矢印キーでマス移動・Enterで選択 / Q・Escで停止

    相手の玉を詰ませれば勝利。王手中は、玉を逃がす・駒を取る・合駒で守ろう。

    敵陣3段に入る／出ると成れます。歩・香・桂は行き所がなくなる移動で自動的に成ります。

    取った駒は成る前に戻り、持ち駒として再利用できます。二歩・打ち歩詰め・行き所のない駒打ちはできません。

    交互に指す制限を外した独自ルールです。同じ盤面・持ち駒・直前の着手側が4回で千日手。連続王手による繰り返しは王手側の負け。入玉宣言・持将棋の点数判定はありません。
