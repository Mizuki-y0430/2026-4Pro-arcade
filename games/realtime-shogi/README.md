# リアルタイム将棋（GAME 06）

4Pro Arcadeの6番目のゲーム。リアルタイムチェスと同じ構成で、Pythonが対局・AI・時間を管理し、ブラウザーは盤面表示と操作を担当します。Python 3.11以上の標準ライブラリだけで動きます。

ランチャーのGAME 06から起動するか、このフォルダで `python web.py --port 8767` を実行して `http://127.0.0.1:8767/` を開きます。

あなたは下側の先手。スタート後、自分の駒と緑の移動先をクリックします。クールタイム（初期0.5秒、0〜1.5秒で変更可能）が終われば、相手を待たずに再び指せます。AIは1秒間隔で指します。持ち駒は盤の左右に表示されます。先手の持ち駒は右側から選びます。成れる場合は選択画面が出ます。矢印キーで盤上の選択を動かし、Enter / Spaceで決定。Q / Escで停止できます。

AIは「よわい」（ランダム）・「ふつう」（駒の価値、成り、王手、安全性で評価）・「つよい」（上位候補で相手の返しも検討）の3段階です。観戦モードはAIが交互に指し、移動した駒は2秒待機します。終局3秒後に自動で次局が始まり、勝敗を集計します。

将棋の基本の駒移動、成り／不成／強制成り、取った成駒の復元、持ち駒の再利用に対応。二歩・行き所のない駒打ち・打ち歩詰め・王手放置・玉の直接捕獲を防ぎ、詰みを自動判定します。基本ルールの参照：[日本将棋連盟・対局規則](https://www.shogi.or.jp/match/taikyoku_rules/)。

交互に指す制限を外した独自ルールです。同じ盤面・持ち駒・直前の着手側が4回出現すると千日手の引き分けにします。その繰り返しの間、ある側の全着手が王手だった場合は、その側の負けです。入玉宣言・持将棋の点数判定は実装していません。

画面ごとに独立した対局を作り、別タブと状態が混ざりません。画面を閉じて30秒更新がなければ対局を停止します。ゲームのフォルダはGit管理対象なので、別PCへのクローンにも含まれます。

- `shogi.py`: 駒移動・合法手・持ち駒・終局・AI
- `web_game.py`: カウントダウン・クールタイム・設定・観戦
- `web.py`: ローカル専用HTTPサーバー（チェスのWebサーバーと同じ方式）
- `web/`: 画面と操作

リポジトリ直下から `python -m unittest discover -s games/realtime-shogi/tests -v` で検証します。
