01 画面をつくる技術

HTML / CSS / JavaScript

ふうせんも、Webの部品でできている。

画面に並ぶふうせんを、プログラムで増やして動かします。

1

HTML 画面の部品

得点欄・ボタン・ふうせんの部品を用意。

2

CSS 見た目

丸い形・色・ひも・揺れを表現。

3

JavaScript 動きと判定

出現・移動・タップ・得点を管理。

ここがポイントふうせんはHTMLの部品。CSSで形をつくり、JavaScriptで動かす。

02 ふうせんが動くしくみ

位置 / 時間 / イベント

位置を少しずつ変えると、浮かんで見える。

ランダムに出したふうせんを、画面の下から上へ動かします。

  1. 1ふうせんを出す位置・大きさを抽選
  2. 2位置を更新速さ × 経過時間
  3. 3画面に反映上の位置を変える
  4. 4タップを判定得点を足して消す

上に動く = y − 速さ × 経過時間

画面の上からの距離を「y」で管理。
前の描画から何秒たったかで、
移動する量を計算します。

タップも「イベント」

押されたふうせんの得点を加算し、
同じふうせんの二重加点を防ぎます。

ここがポイント位置の計算を何度も繰り返し、操作があったら得点を変える。
