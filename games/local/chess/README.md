# リアルタイムチェス

原作：[k4m4b0k02009/chess](https://github.com/k4m4b0k02009/chess)。Web対応：yamamoto。
元のPython / Tkinter版を残し、`yamamoto/web-chess` ブランチでWeb版を追加しています。

## 元のPython版

Python 3.11以上とTcl/Tk（Tkinter）が必要です。外部パッケージは不要です。

```powershell
python chess.py
# または
python -m chess
```

元の `chess.py`、`chess/gui.py`、`chess/game.py`、`chess/ai.py` は変更していません。
`chess/__init__.py` はGUIを必要なときに読み込むように変更し、Web版ではTkinterを不要にしました。

## Web版

Python 3.11以上。追加パッケージ・ビルド・外部通信は不要です。

```powershell
python web.py --port 8766
```

表示された `http://127.0.0.1:8766/` をブラウザーで開きます。終了は起動したターミナルでCtrl+C。
4Pro Arcadeから起動する場合はポートを自動選択し、メニュー内に表示します。一覧へ戻るとサーバーも停止します。

- スタート後、3秒のカウントダウンで対局開始。あなたは白、AIは黒です。
- 駒を選び、緑の印が付いた移動先をクリック / タップ。矢印キーでマス移動、Enter / Spaceでも選択できます。
- ターン制ではありません。自分のクールタイムが終われば、AIの手を待たずに再び動かせます。
- AIの強さは3段階。AIは1秒ごとに動きます。自分のクールタイムは0〜1.5秒で設定できます。
- 停止ボタン / Q / Escで対局全体を停止。AI対戦は再開できます。リセットは盤面と通算成績を初期化します。
- AI同士の観戦では白黒交互に動き、各駒に2秒のクールタイムがあります。終局後3秒で次局へ進みます。停止後に「新しい対局」を押すと新しい盤面から始まります。
- ポーンの昇格先を選択できます。駒の移動アニメーションは設定で切り替えられます。

原作の対局ルールとAIをPython側で共通利用し、ブラウザーは入力・表示・アニメーションを担当します。
開始・停止・クールタイム・観戦の進行管理は追加した `chess/web_game.py` が担当します。
Tkinter版では停止中でも白の駒を動かせますが、Web版では「停止」は白とAIの両方を止めます。
タブごとに対局は独立します。30秒以上画面からの通信が途切れた対局は自動停止します。
通算成績は対局中のメモリーに保持し、リセット・画面の再読み込み・サーバー終了で初期化します。

## 確認

```powershell
python -B -m unittest discover -s tests -v
```

追加ファイルは `web.py`、`web/`、`chess/web_game.py`、`tests/` とこの説明です。
元のルール・AIを作り直すことなく、Python版とWeb版の両方を起動できます。
WebサーバーはローカルPCでの利用を想定しています。
