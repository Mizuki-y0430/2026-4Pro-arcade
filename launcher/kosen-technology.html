01 画面をつくる技術

HTML / CSS / JavaScript

このゲームは、何でできている？

画面と動きを、3つの技術でつくっています。

1

HTML 画面の部品

ボタンや得点欄を用意する。

2

CSS 見た目

色・文字・配置を整える。

3

JavaScript 動きと判定

移動・得点・ゲーム終了を決める。

ここがポイント画面の部品・見た目・動きには、それぞれ役割がある。

02 キャラクターが動くしくみ

JavaScript / Canvas

位置を変えて、何度も描き直す。

キーの操作を、画面の動きに変えています。

  1. 1キーを押す操作を受け取る
  2. 2方向を決める右・左・上・下
  3. 3位置と判定を更新移動・得点・衝突
  4. 4画面を描き直すCanvasに表示

右に進む = 横の番号 + 1

位置を横・縦の番号で管理。
進む方向に合わせて番号を変えます。

Canvas は「絵を描く場所」

更新した位置にキャラクターを描き、
その繰り返しで動きを表します。

ここがポイント操作を受け取り、計算と描画を繰り返すと、ゲームが動く。

03 ルールを決めるしくみ

条件分岐 / 数値

ルールは、「条件」と「数値」で。

JavaScriptが、ゲームの状態を調べて判断します。

単位を取る
→+5

同じマスに来たら

単位を 5 増やす。
通常カード2枚ごとに体も伸びます。

もし単位と位置が同じなら
得点を増やす
ぶつかる
→STOP

頭が壁・自分の体に当たったら

壁・体で終了。落単は6単位まで
続行でき、7単位目で終了します。

ぶつかった対象と落単数で
ゲーム終了を決める
学年で目標を変える
3年生85
4年生125
5年生167
クリアまでの累計取得単位

目標の単位数に届いたら

次の学年へ進級、5年生は卒業。
移動速度や落単の条件は共通です。

取得単位が目標以上なら
クリアにする
