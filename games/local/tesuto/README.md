# デス・モグラたたき

原作：painaplle ／ Web対応：yamamoto

`yamamoto/web-mole` ブランチで、Python + Web版とExcelによる問題管理を追加しています。Pygame版も起動でき、両方が同じExcelから出題します。元の作品はGitの `main` ブランチに残しています。元の設定・ランキングのファイルも残しています。

## Web版の起動

```powershell
python -m pip install -r requirements-web.txt
python web.py --port 8766
```

表示された `http://127.0.0.1:8766/` をブラウザーで開きます。Python 3.11以降とExcel読込用の `openpyxl` を使います。PygameとExcelアプリのインストールはWeb版の実行には不要です。4Pro Arcadeでは `kind: service` として `web.py` を起動すると、ゲーム一覧の画面内で遊べます。

10分野から選び、正解の答えが書かれたモグラをクリック・タップします。正解で＋100点、不正解で−50点（0点未満にはならない）とライフ−1です。穴は2×2の4個で、正解1匹と誤答3匹の計4匹が2〜4秒出現します。答えは大きな白い札に表示します。ライフが0になるか時間切れになると終了し、10文字以内の名前でランキングを登録できます。空欄は `NO_NAME` になります。

- Space：開始。1〜9 / 0：分野を選ぶ（0はLv.10）。
- S：設定。R：ランキング。ランキングでは1〜9 / 0で分野切替、Spaceでメニュー。
- Esc：プレイを中断してメニュー。設定では保存してメニュー。
- 回答ボタンはTabとEnterでも操作できます。

設定は時間10〜180秒、ライフ1〜10、背景・アクセントの色、3種類の文字スタイルに対応します。ランキングは分野別にスコア・残り時間・ライフの順で並べ替え、上位10件を表示します。

## 保存と元の版との違い

Web版は初回に元の `mole_settings.json` と `mole_rankings.json` を読み、`.web-data/settings.json` と `.web-data/rankings.json` にコピーします。以後はWeb専用の記録を使用し、設定・記録の消去も元の版には影響しません。Web専用ファイルはGit管理から除外しています。旧標準の紫・オレンジ配色は赤・白・黒の標準配色に移行します。独自の配色・時間・ライフ設定は保持します。設定・ランキングはこのPC上で共有し、各画面のプレイ状態は別々に管理します。

元の版は30FPSで残り時間を減らします。Web版はPythonサーバーの実時間で判定するため、タブが隠れていても時間が進みます。Escでブラウザーを閉じる代わりにメニューに戻ります。ゲーム一覧へ戻るとサーバーが停止し、途中のプレイは終了します。登録済みの記録は次回も残ります。

HTTPでは正解フラグを送らず、得点と時間の判定はPython側で行います。この版はローカルPC用です。

## Excelで問題を管理する

管理元は `data/questions.xlsx` です。初期ファイルには原作の固定問題284問と10分野の設定を移しています。Pythonのコードを編集せず、Excelで行を追加・編集できます。列名とシート名は変更しないでください。保存後、次のゲーム開始時にWeb版・Pygame版が読み直します。プレイ中の問題はその回が終わるまで変わりません。

「問題一覧」シートは1行が1問です。

| 列 | 入力内容 |
| --- | --- |
| ID | 重複しない識別子。例：`L03-031` |
| 有効 | `有効` または `無効`。無効の問題は出題しません |
| レベル | 1〜10の数字 |
| 問題文 | 画面に表示する質問 |
| 正解 | 正解のモグラに表示する答え |
| 不正解1〜3 | 間違いの答え。最低1個、またはすべて空欄 |
| 補足 | 編集者向けのメモ。ゲームには表示しません |

不正解をすべて空欄にすると、同じ分野の他の有効な問題の正解を候補に使います。候補がない場合は不正解を入力してください。正解と同じ値、重複した不正解候補は登録できません。答えは文字列で入力すると `001`・`1/2`・`sin(x)` などを保持できます。問題・設定のセルには数式を使用しません。

新しい問題は表の末尾に行を追加してください。Excelのテーブル範囲外でも、上記の列に入力してあれば読み込みます。出題しない下書きは `無効` にできます。固定問題の分野には有効な問題を最低1問残してください。

「分野設定」では分野名・説明・出題方式を編集できます。レベル1〜10を各1行ずつ残してください。`自動計算` はLv.1専用で、加減算・乗算の最小値と最大値を変更できます。Lv.1に固定問題を追加すると自動計算と混ぜて出題します。Lv.1を `固定問題` に変更すればExcelに入力した問題だけを出題します。Lv.2〜10は `固定問題` を使用します。

入力ミスがある場合、ゲームの開始時にシート名・行番号を表示します。コマンドでも確認できます。

```powershell
python quiz_database.py
```

Excelは出題用データベースとして読み取り専用で使い、ゲームから書き換えません。ゲームの設定とランキングは従来どおりJSONに保存します。複数人でExcelを編集する場合は更新を調整し、変更した `.xlsx` をGitへコミットしてください。

## ファイルの役割

| ファイル | 役割 |
| --- | --- |
| `data/questions.xlsx` | 問題・分野設定の管理元 |
| `quiz_database.py` | Excel読込・入力検証・出題 |
| `brain_mole.py` | Pygame版の画面・進行。共通Excelから出題 |
| `web_quiz.py` | 以前の関数を使うコード向けの互換入口 |
| `web_game.py` | 出現・回答・時間・得点・保存 |
| `web.py` | ローカルHTTPサーバー・ゲームごとの状態 |
| `web/index.html` | 画面の構造 |
| `web/style.css` | 配色・モグラ・レイアウト |
| `web/game.js` | ボタン・キーボード操作・画面更新 |

## 元のPygame版

Python 3.12の仮想環境に `pygame-ce==2.5.8` と `openpyxl==3.1.5` をインストールして、ゲームのフォルダで `python brain_mole.py` を実行します。`pygame` と `pygame-ce` は同じモジュールを提供するため、両方を同じ環境にインストールしないでください。`tesuto-3` コマンドは元からパッケージの挨拶を表示するだけです。
